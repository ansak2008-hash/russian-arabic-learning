# الدرس 05: الطعام والمقهى
# Урок 05: Еда и кафе

**المستوى / Уровень:** مبتدئ / Начальный  
**الموضوع / Тема:** طلب مشروب وطعام بسيط

## 1. الروسية للعرب / Русский для арабов

### مفردات جديدة / Новая лексика

| الروسية | النطق بالعربية | المعنى |
|---|---|---|
| вода | ڤادا | ماء |
| кофе | كوڤي | قهوة |
| чай | تشاي | شاي |
| хлеб | خليب | خبز |
| меню | مينيو | قائمة الطعام |
| счёт | شوت | الحساب |
| сахар | ساخار | سكر |
| молоко | مالاكو | حليب |

### جمل يومية / Повседневные предложения

- **Можно воду, пожалуйста?** — هل يمكن ماء، من فضلك؟
- **Мне, пожалуйста, чай.** — أريد شايًا، من فضلك.
- **Кофе без сахара.** — قهوة بلا سكر.
- **У вас есть молоко?** — هل لديكم حليب؟
- **Можно счёт, пожалуйста?** — الحساب، من فضلك.

## 2. العربية للروس / Арабский для русских

### مفردات جديدة / Новая лексика

| العربية | النطق بالحروف الروسية | المعنى الروسي |
|---|---|---|
| مَاء | маа | вода |
| قَهْوَة | кахва | кофе |
| شَاي | шай | чай |
| خُبْز | хубз | хлеб |
| قَائِمَة الطَّعَام | каимат ат-та'ам | меню |
| حِسَاب | хисаб | счёт |
| سُكَّر | суккар | сахар |
| حَلِيب | халииб | молоко |

### جمل يومية / Повседневные предложения

- **مَاءٌ مِنْ فَضْلِكَ.** — Воду, пожалуйста.
- **أُرِيدُ شَايًا.** — Я хочу чай.
- **قَهْوَةٌ بِدُونِ سُكَّرٍ.** — Кофе без сахара.
- **الْحِسَابُ مِنْ فَضْلِكَ.** — Счёт, пожалуйста.

## 3. حوار قصير / Короткий диалог

**Русский**

— Здравствуйте! Что будете?  
— Чай и хлеб, пожалуйста.  
— С сахаром?  
— Нет, без сахара. Можно счёт?

**العربية**

— مرحبًا! ماذا تريد؟  
— شاي وخبز، من فضلك.  
— مع السكر؟  
— لا، من دون سكر. الحساب من فضلك.
