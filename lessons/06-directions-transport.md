# Урок 06: Направления и транспорт

**الموضوع / Тема:** السؤال عن مكان ووسيلة النقل

## 1. الروسية للعرب / Русский для арабов

### مفردات جديدة / Новая лексика

| الروسية | النطق بالعربية | المعنى |
|---|---|---|
| где | گدييه | أين |
| улица | أوليتسا | شارع |
| метро | ميترو | مترو الأنفاق |
| автобус | أوتوبيس | حافلة |
| остановка | أستانوفكا | موقف / محطة |
| направо | ناپراڤا | إلى اليمين |
| налево | ناليڤا | إلى اليسار |
| прямо | پرياما | إلى الأمام / مباشرة |

### جمل يومية / Повседневные предложения

- **Где метро?** — أين المترو؟
- **Где автобусная остановка?** — أين موقف الحافلة؟
- **Идите прямо.** — اذهب إلى الأمام.
- **Потом направо.** — ثم إلى اليمين.
- **Это далеко?** — هل هذا بعيد؟

## 2. العربية للروس / Арабский для русских

### مفردات جديدة / Новая лексика

| العربية | النطق بالحروف الروسية | المعنى الروسي |
|---|---|---|
| أَيْنَ | айна | где |
| شَارِع | шари' | улица |
| مِتْرُو | метро | метро |
| حَافِلَة | хафиля | автобус |
| مَوْقِف | мавкиф | остановка |
| يَمِين | ямин | направо / правая сторона |
| يَسَار | ясар | налево / левая сторона |
| مُبَاشَرَةً | мубашаратан | прямо |

### جمل يومية / Повседневные предложения

- **أَيْنَ الْمِتْرُو؟** — Где метро?
- **أَيْنَ مَوْقِفُ الْحَافِلَةِ؟** — Где автобусная остановка?
- **اِذْهَبْ مُبَاشَرَةً.** — Идите прямо.
- **ثُمَّ إِلَى الْيَمِينِ.** — Потом направо.

## 3. حوار قصير / Короткий диалог

**Русский**

— Извините, где метро?  
— Идите прямо, потом направо.  
— Это далеко?  
— Нет, совсем близко.

**العربية**

— عذرًا، أين المترو؟  
— اذهب مباشرةً، ثم إلى اليمين.  
— هل هو بعيد؟  
— لا، قريب جدًا.

## 4. تدرّب / Практика

اسأل عن المترو أو موقف الحافلة، ثم أعطِ اتجاهين على الأقل.
