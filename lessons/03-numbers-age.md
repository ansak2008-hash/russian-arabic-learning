## 1. الروسية للعرب / Русский для арабов

### مفردات جديدة / Новая лексика

| الروسية | النطق بالعربية | المعنى |
|---|---|---|
| Сколько? | سكولكا | كم؟ |
| лет | ليت | سنة / سنوات في التعبير عن العمر |
| один | أدين | واحد |
| два | دڤا | اثنان |
| три | تري | ثلاثة |
| четыре | تشيتيري | أربعة |
| пять | پيات | خمسة |
| десять | ديسيت | عشرة |
| двадцать | دڤاتسات | عشرون |
| тридцать | تريتسات | ثلاثون |

### جمل يومية / Повседневные предложения

- **Сколько тебе лет?** — كم عمرك؟ (غير رسمي)
- **Сколько вам лет?** — كم عمرك؟ (بصيغة مهذبة)
- **Мне двадцать лет.** — عمري عشرون سنة.
- **Мне двадцать пять лет.** — عمري خمس وعشرون سنة.
- **Мне тридцать лет.** — عمري ثلاثون سنة.

**ملاحظة:** بعد 1 نقول عادةً *год*، وبعد 2 و3 و4 غالبًا *года*، وبعد 5–20 *лет*. توجد قواعد إضافية للأعداد المركبة.

## 2. العربية للروس / Арабский для русских

### مفردات جديدة / Новая лексика

| العربية | النطق بالحروف الروسية | المعنى الروسي |
|---|---|---|
| عُمْر | умр | возраст |
| سَنَة | сана | год |
| سِتَّة | ситта | шесть |
| سَبْعَة | саб'а | семь |
| ثَمَانِيَة | самания | восемь |
| تِسْعَة | тис'а | девять |
| عَشَرَة | ашара | десять |

| خَمْسَة | хамса | пять |
| ثَلَاثُون | салясун | тридцать |
| أَرْبَعُون | арба'ун | сорок |

### جمل يومية / Повседневные предложения

- **كَمْ عُمْرُكَ؟** — Сколько тебе лет?
- **عُمْرِي عِشْرُونَ سَنَةً.** — Мне двадцать лет.
- **عُمْرِي خَمْسٌ وَعِشْرُونَ سَنَةً.** — Мне двадцать пять лет.

**ملاحظة:** تتغير صيغة العدد في العربية بحسب المعدود والسياق. تُستخدم هنا جمل معيارية للتعلّم الأولي.

## 3. حوار قصير / Короткий диалог

**Русский**

— Сколько тебе лет?  
— Мне двадцать пять лет. А тебе?  
— Мне двадцать лет.

**العربية**

— كم عمرك؟  
— عمري خمس وعشرون سنة. وأنت؟  
— عمري عشرون سنة.

## 4. تدرّب / Практика

قل عمرك بالروسية، ثم اسأل شخصًا آخر بصيغة مهذبة: **Сколько вам лет?**
