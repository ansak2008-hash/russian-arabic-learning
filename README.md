# تعلّم الروسية للعرب — والعربية للروس
# Русский для арабов — арабский для русских

مشروع تعليمي ثنائي الاتجاه يساعد الناطقين بالعربية على تعلّم الروسية، ويساعد الناطقين بالروسية على تعلّم العربية، من خلال دروس قصيرة وواضحة ومفردات عملية.

Образовательный проект для изучения русского языка арабоговорящими и арабского языка русскоговорящими. Материалы включают короткие уроки, полезную лексику и понятную транскрипцию для начинающих.

## تنظيم المشروع

- `lessons/` — الدروس / уроки.
- `vocabulary/word-ledger.csv` — سجل المفردات لمنع تكرار الكلمات الجديدة / реестр лексики для контроля новых слов.
- `pdf/` — ملفات PDF الجاهزة للطباعة / PDF-файлы для печати.

## قواعد إعداد الدروس

1. كل درس ثنائي الاتجاه: الروسية للعرب، والعربية للروس.
2. تُعرض الكلمة الأصلية ومعناها والترجمة الصوتية التقريبية عند الحاجة.
3. تُسجَّل المفردات الجديدة في `vocabulary/word-ledger.csv`.
4. لا تُقدَّم مفردة مسجّلة سابقًا على أنها مفردة جديدة في درس لاحق. يمكن إعادة استخدامها للمراجعة، مع توضيح أنها مراجعة.
5. تُستخدم علامات النبر في الكلمات الروسية عندما تساعد المبتدئ على النطق.
6. تكون الشروحات قصيرة، دقيقة، ومناسبة للمبتدئين.

## Правила подготовки уроков

1. Каждый урок включает оба направления: русский для арабов и арабский для русских.
2. Новые слова добавляются в `vocabulary/word-ledger.csv`.
3. Слово из реестра нельзя выдавать за новое в следующих уроках; его можно повторять для закрепления с пометкой «повторение».
4. Уроки должны быть короткими, точными и понятными начинающим.

## المساهمة والتحديث / Обновление материалов

يجب تحديث سجل المفردات عند إضافة أي درس، والتحقق من عدم تكرار الكلمات الجديدة قبل اعتماد الدرس.

При добавлении урока необходимо обновить реестр лексики и проверить, что новые слова не дублируют ранее зарегистрированные.
