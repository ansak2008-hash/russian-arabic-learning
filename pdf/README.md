# ملفات PDF / PDF-файлы

يُحفظ هنا إصدار PDF النهائي لكل درس بعد مراجعته لغويًا وتنسيقيًا.

Здесь хранятся окончательные PDF-версии уроков после языковой и визуальной проверки.

## قواعد النشر / Правила публикации

- استخدم أسماء ملفات واضحة، مثل `01-greetings-ar-ru.pdf`.
- تأكد من ظهور العربية من اليمين إلى اليسار والروسية من اليسار إلى اليمين.
- استخدم خطًا يدعم الحروف العربية والروسية.
- راجع علامات التشكيل العربية وعلامات النبر الروسية بعد التصدير.
- لا تنشر PDF قبل مقارنة مفرداته بسجل `../vocabulary/word-ledger.csv`.
- يُحفظ ملف المصدر بصيغة Markdown داخل `lessons/`.

- Используйте понятные имена файлов, например `01-greetings-ar-ru.pdf`.
- Проверьте направление письма: арабский текст справа налево, русский — слева направо.
- Используйте шрифт с поддержкой арабского и кириллического письма.
- После экспорта проверьте арабские диакритические знаки и ударения в русских словах.
- Перед публикацией сравните лексику с реестром `../vocabulary/word-ledger.csv`.
